# 安卓智能连点器 (Auto Clicker)

> 基于无障碍服务开发的轻量级连点工具，支持悬浮窗控制、多点循环点击、自定义间隔与息屏自动停止。

## ⚠️ 项目状态说明

本仓库为 **源码阅读/学习版本**。因本地开发环境意外丢失原始工程文件，故基于最终发布的 APK 安装包，通过 `jadx` 反编译恢复了核心业务逻辑代码与资源文件。

**当前仓库包含：**
- ✅ 完整的 Java 业务逻辑源码（`/sources`）
- ✅ 所有布局、图标及无障碍服务配置（`/res`）
- ✅ 完整的 `AndroidManifest.xml` 清单文件
- ✅ 详细的技术架构分析报告（`ARCHITECTURE.md`）

**当前仓库不包含（无法直接编译）：**
- ❌ Gradle 构建脚本（`build.gradle`）
- ❌ 项目级配置文件

如需完整可编译的 Android Studio 工程，可参考 `ARCHITECTURE.md` 中的技术要点自行搭建，或联系我获取帮助。

## 🔧 技术栈亮点

- **无障碍手势注入**：基于 `AccessibilityService` + `GestureDescription` 实现屏幕模拟点击，无需 Root 权限。
- **悬浮窗交互**：利用 `WindowManager` 实现常驻悬浮球控制（开始/停止/状态显示）。
- **配置持久化**：通过 `SharedPreferences` 保存点击坐标、间隔时长等用户设置。
- **定时循环机制**：`Handler.postDelayed()` 驱动周期点击任务，支持随机间隔变化。
- **息屏保护**：监听 `SCREEN_OFF` 广播，屏幕关闭时自动停止连点，防止误触。

## 📱 功能特性

- 单点 / 多点序列点击（支持记录坐标）
- 自定义点击间隔（毫秒级）
- 循环次数限制（无限循环 / 指定次数）
- 悬浮球实时状态反馈（运行中/已停止/点击计数）
- 权限引导（无障碍 + 悬浮窗授权一站式跳转）

## 📖 使用说明

### 1. 权限准备（首次使用）

在开始使用前，请确保已授予以下权限：

- **无障碍服务权限**：在系统设置中搜索“无障碍”或“辅助功能”，找到本应用并开启。
- **悬浮窗权限**：允许本应用在其他应用上层显示（用于显示悬浮球）。

> 本应用会在主界面引导你一键跳转至对应权限设置页。


### 2. 主界面功能说明

#### 状态显示区

顶部状态栏显示当前连点器状态：
- **“就绪”**：等待开始
- **“连点运行中”**：正在执行连点任务

---

#### 点击模式选择

| 模式 | 说明 |
| :--- | :--- |
| **单点 + 半径** | 在指定坐标点周围一定半径范围内随机点击，模拟人工点击的随机性。 |
| **多点排序** | 按顺序依次点击多个预设坐标点。点击下方 **“+ 添加位置”** 按钮可逐个录入多个点位。 |

---

#### 单点模式设置（选择“单点 + 半径”时显示）

![单点模式界面]

- **X / Y**：点击目标的屏幕绝对坐标（单位为像素）。
- **R (px)**：随机点击半径（单位：像素）。开启“圆形范围内随机点击”后，实际点击位置会在以（X，Y）为圆心、R为半径的圆形区域内随机选取。
- **“选择位置”按钮**：点击后进入坐标拾取模式，在屏幕上任意位置点击，即可自动捕获该点的 X/Y 坐标。

---

#### 多点排序模式设置（选择“多点排序”时显示）

![多点排序界面]

- 点击 **“+ 添加位置”** 依次录入多个点击坐标。
- 每个点位可单独查看和删除。
- 运行时会按添加顺序依次循环点击所有点位。

---

#### 间隔范围（随机变化）

- **最小 / 最大**：设置两次点击之间的时间间隔（单位：毫秒）。
- 开启“间隔随机变化”后，每次点击的间隔在最小值和最大值之间随机变化，避免被检测为机器操作。
- 关闭“间隔随机变化”后，固定为“最小”值。

---

#### 次数限制

- 设置连点循环的总次数。输入 `0` 表示无限循环，直到你手动停止为止。

---

#### 控制按钮

- **“开始连点”**：点击后开始执行连点任务，顶部状态变为“连点运行中”。再次点击则停止连点。


### 3. 悬浮球控制（运行中）

点击“开始连点”后，屏幕会显示一个**悬浮球**。

点击悬浮球，上方会展开四个功能小球：

| 图标/按钮 | 功能说明 |
| :--- | :--- |
| **选取位置** | 进入坐标拾取模式，点击屏幕任意位置获取 X/Y 坐标（自动填充到当前选中的点位）。 |
| **开始 / 停止** | 切换连点任务的运行状态（开始/停止）。 |
| **切换模式** | 在“单点 + 半径”和“多点排序”之间快速切换。 |
| **删除存档** | 清除所有已保存的配置数据（点位、间隔、次数等），恢复到初始状态。 |

![运行中状态]
> 悬浮球上方的状态会同步显示当前运行状态。


### 4. 配置自动保存

- 所有设置（坐标、半径、间隔、次数、模式等）**自动保存**，无需手动点击保存按钮。
- 下次打开应用时，自动加载上次的配置，可直接点击“开始连点”使用。
- **首次使用**或点击悬浮球上的 **“删除存档”** 后，需要重新设置点位再开始。


### 5. 息屏自动停止

当手机屏幕关闭（锁屏）时，连点任务会自动停止，防止在口袋中误触。


### 6. 使用流程速查

1. 开启**无障碍服务**和**悬浮窗权限**。
2. 选择点击模式（单点+半径 / 多点排序）。
3. 设置坐标和参数（单点模式使用“选择位置”拾取坐标；多点排序使用“+ 添加位置”逐个录入）。
4. 设置点击间隔范围（建议 100ms ~ 300ms）。
5. 设置循环次数（0 为无限）。
6. 点击 **“开始连点”**。
7. 点击悬浮球上方的 **“停止”** 小球来结束任务。
